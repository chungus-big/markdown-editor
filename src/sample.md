# Markdown Editor (CommonMark + GFM)

Добро пожаловать в легковесный редактор **Markdown** на **Rust** и **Slint**!

Этот документ содержит все примеры и тестовые случаи для проверки функциональности редактора: форматирование текста, таблицы GFM, списки задач, блоки кода, цитаты, перенос длинных строк и сноски.

---

## 1. Стилизация текста (Text Styling)

### 1.1. Жирный шрифт и курсив
Здесь проверяется **жирный текст на латинице (Bold Text)**, а также **жирный русский текст с кириллицей**.
Поддерживается альтернативный синтаксис: __жирный текст через подчеркивание__.
Комбинация стилей: ***жирный курсив (Bold Italic)*** и **_жирный курсив с подчеркиванием_**.
Символы пунктуации вплотную к маркеру: **Внимание!**, **(Важно)**, **Ключ:** значение.

### 1.2. Инлайн-код и специальные символы
Обычный инлайн-код: вызов функции `calculate_stats()` и структуры `MarkdownBlockData`.
Инлайн-код с тегами XML/HTML: `<RootNamespace>SteamLib</RootNamespace>` и `<PackageReference Include="Slint" />`.
Инлайн-код со скобками и синтаксисом C# 12: `[GeneratedRegex]`, primary constructors, `[..]`, `using var`.
Инлайн-код с флагами командной строки: `-warnaserror` и `--verify-no-changes`.
Спецсимволы внутри кода: `a && b || c != d`, `Map<String, List<int>>`, `$HOME/path`.
Кириллица внутри инлайн-кода: `переменная_с_русским_именем = 100`.

### 1.3. Комбинации, зачеркивание и ссылки
- **`TimeAligner`**: внедрена надёжная защита от гонок данных.
- Зачеркнутый текст: ~~Устаревшие синхронные вызовы~~ заменены на современные реализации.

## 6. Проверка переноса длинных строк (Word Wrap)

### 6.1. Длинный абзац текста
Данный абзац специально сформирован из непрерывного длинного текста на русском языке для тщательной валидации механизма автоматического переноса строк (Word Wrap) в панели предпросмотра редактора Markdown. В режиме включенного переноса строк ширина контейнера строго зафиксирована по видимой области панели, благодаря чему текст мягко переносится по границам слов на любое количество строк, сохраняя идеальную читаемость при любом размере окна.

### 6.2. Длинный пункт списка
- Устранена проблема с пустыми заголовками подтверждений в русской локализации и неработающим вторым текстовым блоком: класс `Confirmation` теперь гарантирует fallback `TypeName`, реализует интерфейс `INotifyPropertyChanged`, скраппер `MobileConfirmationScrapper` извлекает название товара и цену с поддержкой всех популярных языков Steam (EN, RU, UA, DE, FR, ES, PT, IT, PL, TR, ZH, JA, KO), эвристики валют и Span-очистки без строковых аллокаций (`Chroma 3 Case — 2,30€`), а конвертер `ConfirmationTitleConverter` с `MultiBinding` в Avalonia мгновенно локализует тип операции при смене языка на лету без перезапуска.
